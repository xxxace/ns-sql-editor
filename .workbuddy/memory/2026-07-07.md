## 连接功能「导出复制 / 导入粘贴」已实现

- 用户关键反馈：**导入/导出纯逻辑必须独立成模块（目录），由消费者调用，不可全塞进 `auth` store 耦合**。据此调整为分层架构：
  - `src/utils/connectionTransfer.ts`（纯模块：serialize/parse/resolveImportItems，无 Pinia/UI 依赖）
  - `src/utils/clipboard.ts`（copyToClipboard，带 HTTP fallback）
  - `src/stores/auth.ts`：仅 1 个编排方法 `importConnections`，逻辑委托模块
  - `src/components/ConnectionTransferDialog.vue`（export/import 双模式弹窗）
  - `src/components/LoginDialog.vue`：每条连接「复制」+ 页脚「复制全部 / 粘贴导入」+ 挂载弹窗
- 图标：复制=DocumentCopy，导入=Upload（Paste 在本版 @element-plus/icons-vue 不存在）。
- 验证：`npm run build`（vue-tsc 类型检查 + vite build）通过，仅第三方 @vueuse 注释告警。
- 方案文档已同步为最终分层架构（v0.2）。
