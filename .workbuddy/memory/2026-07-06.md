## Ctrl+Shift/F 快捷键修复（第二轮：纠正）

- **上轮误判**: 认为是 Monaco `addAction` 惰性注册 bug → 尝试分离 keybinding 到 `addKeybindingRules` → 无效
- **真正根因**: **Windows 中文输入法简繁体切换冲突**。微软拼音/搜狗拼音等中文输入法在系统层（TSF）拦截 `Ctrl+Shift+F` 用于简繁体切换，浏览器和 Monaco 收不到该按键
  - 右键菜单弹出时 IME 退出文本编辑上下文 → 快捷键不被拦截 → 能生效
  - 这完美解释了"必须右键后才生效"的现象
- **正确修复**: 快捷键从 `Ctrl+Shift+F` 改为 `Shift+Alt+F`（VS Code 格式化文档标准快捷键，不与任何 IME 冲突）
- **改动**: `src/components/SqlEditor.vue` 一行：`keybindings: [Monaco.KeyMod.Shift | Monaco.KeyMod.Alt | Monaco.KeyCode.KeyF]`
- **已撤销**: monaco.ts 的 `addFormatKeybinding`（无用改动）

## Undo/Redo 加载语句后回退到上一语句 Bug 修复

- **Bug**: 切换语句后 Ctrl+Z 能回到上一个语句内容
- **根因**: watch `store.currentSql` 用 `editor.executeEdits()` 同步内容 → 每次加载都推入 undo 栈
- **修复**: 
  - watch 改用 `editor.setValue()` → 清空 undo 栈，加载内容就是"最初数据"
  - `runFormat` 绕过 watch，直接用 `executeEdits` 写 editor + 再同步 store → 格式化可撤销
- **关键区分**: 加载/回滚 = setValue（不可撤销），格式化 = executeEdits（可撤销）
- 构建通过 ✅

## 锁定状态同步 Bug 修复 + 右键菜单新功能

- **Bug**: 切换语句后锁定按钮与编辑器 readOnly 不一致
  - 根因: `SqlEditor.vue` 的 `store.currentSql` watch 的 `nextTick` 用 `wasReadOnly` 快照恢复 readOnly，与后续 `isLoadingSql` 重置产生 race condition
  - 修复: nextTick 改用实时 `store.isLocked || store.isLoadingSql` 而非快照
- **新功能**: Monaco 右键菜单添加两项
  1. **刷新语句** (`ns-reload-statement`): emit `reload` → EditorView 检查 `isModified`，有未保存则弹确认框，确认后 `loadStatement(true)` 跳过草稿提示
  2. **切换编辑锁定** (`ns-toggle-lock`): 动态标签 🔒/🔓，watch `isLocked` 自动更新，保存期间 `isLoadingSql` 先 return
- **改动 2 文件**: `SqlEditor.vue` (+emits/+2 actions/+watch), `EditorView.vue` (+@reload/+handleReloadStatement)
- 构建通过 ✅
