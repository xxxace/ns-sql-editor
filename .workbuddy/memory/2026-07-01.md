2. **专注模式按钮 toggle** → 根据 isFocusMode 切换「专注」/「退出专注」文案和图标
3. **Diff 时编辑器隐藏** → EditorView 在 diffVisible 时隐藏 SqlEditor(.collapsed)，DiffPanel 改为 flex-1 占满
4. **Undo/Redo 不工作** → 添加 Ctrl+Shift+Z → redo 快捷键（Monaco 默认只有 Ctrl+Y）
5. **Oracle 格式化** → 依次尝试 plsql → sql dialect，兜底全局失败提示
6. **草稿删除** → 工具栏草稿按钮改为下拉菜单：保存草稿 / 管理草稿（打开抽屉）
7. **切换语句提醒** → MenuTree + StatementList 都在切换前检查 isModified，弹 confirm
8. **登录弹窗无法关闭** → LoginDialog 加 closable prop；首次登录不可关，切换连接可关

## Bug 修复：第二轮 — 草稿/Diff/格式化undo

1. **草稿功能异常** → SqlToolbar 中 el-dropdown 内包裹了 el-tooltip，tooltip 劫持点击事件导致下拉菜单打不开，移除外层 el-tooltip
2. **Diff 功能异常** → DiffPanel 用 v-if 控制显隐，组件挂载时 diffVisible 已是 true 但 watch 非 immediate，initDiff() 从未执行。添加 onMounted 钩子在挂载时检查并初始化
3. **格式化后 undo/redo 失效** → SqlEditor 用 `editor.setValue()` 同步 Store，Monaco 的 setValue() 会清空 undo stack。改用 `editor.executeEdits()` + `pushUndoStop()`，变更被推入 undo 栈，Ctrl+Z 可回退整段格式化

## Bug 修复：第三轮 — 草稿隔离/面板resize/Loading/禁用/添加连接跳转

1. **草稿管理入口** → 草稿下拉按钮移除 disabled 条件，「管理草稿」始终可点，「保存当前草稿」按 selectedStatement 禁用
2. **草稿按连接隔离** → DraftRecord 新增 connectionName/objectId/tabseq 字段；draftKey 格式改为 `draft_{连接名}_{OBJECTID}_{TABSEQ}`；getAllDrafts(connectionName) 按前缀过滤
3. **面板 resize** → EditorView 添加拖拽手柄（4px 竖线，hover 显示 accent 色），menuWidth(180) / stmtWidth(220) 响应式，范围 120~500px
4. **草稿跳转不弹确认** → handleDraftLoad 设 skipNextLoad=true，loadStatement 检测此标志跳过网络请求 + 不弹草稿提示
5. **Loading 状态** → 编辑区叠加半透明毛玻璃遮罩层 + spin 动画 + 「加载语句中...」文字
6. **Loading 时全链路禁用** → store 新增 isLoadingSql，SqlToolbar 按钮全禁、MenuTree/StatementList click 检查、resize 拖拽禁止
7. **添加连接直达新建tab** → LoginDialog 新增 defaultTab prop，SqlToolbar「添加连接」emit open-login-new → LoginDialog defaultTab='new'
