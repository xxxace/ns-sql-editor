## 登录账户联动功能 — 开发方案编写

- 基于 `登录账户和其它账户联动功能需求.txt` 和当前 ns-sql-editor 项目代码探索，输出了完整开发方案文档
- 方案文档: `登录账户和其它账户联动功能-开发方案.md`

### 关键决策（方案建议）

1. **架构选型**: 推荐「混合模式」— 独立 linkageStore + 嵌入主界面的 LinkagePanel，而非独立模块或全嵌入
2. **对比匹配**: 以 DSNAME 为主匹配键，DBQUERY hash 为辅助
3. **同步方向**: 仅单向（目标→主会话）
4. **并发方案**: 乐观锁+重试（前端），理想情况后端提供原子化接口
5. **UI 形态**: 侧边抽屉（复用 DraftDrawer 模式）

### 待用户确认的 8 个问题

已在文档 5.4 节详细列出，涵盖匹配算法、元数据归属、DSNAME 可空性、DSSTMTY 语义、UI 形态、后端接口、批量上限、辅助字段处理。
